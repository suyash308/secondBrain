# Contributing to Second Brain

## Reporting Bugs
Open a GitHub issue with steps to reproduce, your Android version, and device model.

## Requesting Features
Open a GitHub issue with the feature description and your use case.

## Submitting Code
1. Fork the repo
2. Create a branch: git checkout -b feature/your-feature-name
3. Make your changes following the patterns in CLAUDE.md
4. Test on a real device
5. Submit a pull request with a clear description of what changed and why

## Code Style
Follow the rules in CLAUDE.md in the repo root.
